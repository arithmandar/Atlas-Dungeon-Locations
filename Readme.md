# Atlas Dungeon Locations

Dungeon location maps for the World of Warcraft Atlas addon.

Atlas Dungeon Locations is an optional Atlas plugin that provides maps showing
where dungeons are located. It requires the Atlas core addon and does not run
as a standalone addon.

## Downloads

- [Atlas Dungeon Locations on CurseForge](https://www.curseforge.com/wow/addons/atlas-dungeon-locations)
- [Atlas core addon on CurseForge](https://www.curseforge.com/wow/addons/atlas)

Choose releases compatible with your WoW client. Map coverage may vary by release.

## Installation

1. Install the Atlas core addon.
2. Install Atlas Dungeon Locations for the same WoW client.
3. Enable both addons in the character selection screen's AddOns list.
4. Open Atlas with `/atlas` and select the dungeon location maps.

For manual installation, extract the addon into the `Interface/AddOns`
directory of the WoW client you use. Preserve the addon folder structure
and avoid an extra wrapper folder.

## About This Plugin

Atlas Dungeon Locations was originally included in Atlas. It is now distributed
as a separate addon so players can choose whether to install its maps.

This plugin focuses on dungeon locations rather than layouts inside dungeons.
For dungeon interior maps, install the corresponding Atlas instance map modules.

This repository contains the Atlas Dungeon Locations plugin, not the Atlas core.
